About Lunaris

What is Lunaris?

Lunaris is a modular creature-battling roguelike game where players explore procedurally generated zones, capture and train unique creatures, and engage in strategic turn-based battles.

Development

Lunaris is being developed as a modular, expandable game system. The core mechanics are designed to be flexible, allowing for easy addition of new creatures, abilities, zones, and game modes.

Technology

  • Built with vanilla JavaScript
  • WebSocket-based multiplayer
  • Responsive web design
  • Modular architecture

Roadmap

Future updates will include:

  • More creatures and zones
  • Enhanced multiplayer features
  • Additional game modes
  • Visual improvements and animations
