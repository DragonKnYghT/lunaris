About Lunaris

Our Story

Lunaris is a creature-battling roguelike game inspired by classic monster-collecting games. We wanted to create something unique that combines strategic combat with roguelike progression.

Technology

Built with modern web technologies:

  • HTML5, CSS3, JavaScript (ES6+)
  • WebSocket for multiplayer
  • Responsive web design
  • Modular architecture

Roadmap

Future updates will include:

  • More creatures and zones
  • Enhanced multiplayer features
  • Additional game modes
  • Visual improvements and animations
